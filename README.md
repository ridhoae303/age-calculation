# Age Calculator GUI

A simple age calculator app made with Python and Tkinter.

Nothing crazy, just a small project I tweaked because I was bored.

## Features

- Calculate age by years, months, and days
- Realtime current date option
- Manual date input
- Auto day limit adjustment
- Basic server request test
- Simple GUI using Tkinter

## Requirements

- Python 3

## Run

```python
python "AgeCalculator.py"
```
